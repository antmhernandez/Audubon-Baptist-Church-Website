Audubon on your phone

The website,
ready like an app.

Install Audubon on a phone, tablet, or computer for a home-screen icon, an app-like window, quick access to sermons and the calendar, and offline fallback for the application shell.

Installation steps vary by operating system and browser. This button will use the browser’s native installer when available and show the correct manual steps when it is not.

01

One site.
One app.

There is no separate app to keep in sync. The installed version opens the same Audubon website and prefers the newest online files whenever a connection is available.

Current

The installed app checks the live website and service worker for updates when it opens.

Quick

Open Audubon from the home screen or app launcher without first finding a browser bookmark.

Flexible

Public pages, Sermons, Member Home, Calendar, and future notifications can share the same application shell.

If your browser asks you to install

Choose Install.

On browsers with a native PWA installer, the button above opens it directly.

On iPhone and iPad, use the browser Share menu and choose Add to Home Screen, then enable Open as Web App when that option is shown.

On browsers without native PWA installation, the same button provides a short fallback guide rather than failing silently.
