Audubon on your phone

The website,
ready like an app.

Install Audubon for a home-screen icon, an app-like window, fast access to sermons and member tools, and a public offline fallback when a connection drops.

The app uses the same website and checks for current deployed files whenever it opens online.

01

One site.
One app.

There is no second app to keep in sync. The installed version opens the same Audubon website, so improvements to the site flow into the installed app too.

Current

When online, the app prefers the live deployed site and asks its service worker to check for updates.

Quick

Open Audubon from the Home Screen or app launcher without hunting for a browser bookmark.

Private by design

Only the public/static app shell is kept for offline fallback; private member/admin routes are excluded.

Installation help

Use the browser’s own installer.

Where the browser exposes a native PWA install prompt, Get the App! opens it directly.

On iPhone and iPad, use the browser Share menu and choose Add to Home Screen, then enable Open as Web App when that option is shown.

If a browser does not expose a PWA installer, the same button shows platform-appropriate fallback instructions instead of silently failing.
